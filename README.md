# ☁️ Azure Cloud Lab

Welcome to my hands-on Microsoft Azure cloud engineering lab.

This repository documents my practical learning and implementation of Azure infrastructure, networking, identity, monitoring, automation, containers, and cloud troubleshooting.

The goal of this project is to strengthen Azure engineering skills by building real environments, documenting architectural decisions, troubleshooting issues, and automating cloud infrastructure.

---

## 🎯 Lab Objectives

Through this repository I will build hands-on experience with:

- Azure Resource Groups
- Azure Virtual Networks (Vnets)
- Subnets
- Network Security Groups (NSGs)
- Azure Virtual Machines
- Linux on Azure
- Azure Storage
- Microsoft Entra ID
- Identity and Access Management
- Azure Monitor
- Log Analytics
- Azure CLI
- PowerShell
- Infrastructure Automation
- Azure Kubernetes Service (AKS)
- Cloud Troubleshooting
